Five cameras, one OBS program

Use this kit to run a Sony ZV-1F, one wired GoPro, two wireless GoPros and a DJI Osmo 360 from one Windows, Linux or macOS computer. OBS gives you one 1080p30 program, a five-camera grid, a picture-in-picture shot and five full-screen camera scenes. Camera video stays on the field network until you choose an output destination in OBS. Work through one checkpoint at a time.

Compatibility decision. This build uses USB 3.x host ports and 5 Gb/s data cables. The Sony's USB-C port negotiates USB 2.0 and delivers native 720p MJPEG. The GoPro uses USB networking. Windows and macOS expose it through GoPro Webcam. On Linux, supported models stream a webcam picture directly over the USB network interface. If the requirement is native UVC at a negotiated 5 Gb/s on both camera ends, these two named cameras cannot deliver that combination. The DJI contributes a flat single-lens angle at 1080p30. Bandwidth budget Payload calculation
USB 3.0 / USB 3.2 Gen 1 5.0 Gb/s signaling × 8/10 coding = 4.0 Gb/s before protocol overhead, per link. Devices behind one hub share its uplink. The controller's PCIe link and other devices also matter.
USB 2.0 High-Speed on the Sony 480 Mb/s signaling with lower usable payload. SuperSpeed capacity on the host does not raise this link rate.
Hypothetical uncompressed YUY2 width × height × 16 bits/pixel × fps. 720p30 = 442.37 Mb/s. 1080p30 = 995.33 Mb/s. Neither is the Sony's transmitted MJPEG rate.
Worked compressed budget At an assumed 150,000 bytes/JPEG × 30 × 8, Sony video is 36 Mb/s. Its 48,000 × 16 × 2 PCM audio adds 1.536 Mb/s. Add ~6 Mb/s for GoPro USB video → 43.54 Mb/s across the two inputs before packet/USB overhead. MJPEG changes with detail and motion.

For a measured budget on Windows, close applications using the Sony, run the commands below in PowerShell and replace the quoted device name with the DirectShow name printed by the first command. Film moving foliage or a detailed scene. FFmpeg's device enumeration can exit with an error after printing the list. The last command reports the average and highest single-frame size. Multiply bytes by 30 × 8 ÷ 1,000,000 for estimated Mb/s at 30 fps. The peak-frame figure is a conservative projection.

ffmpeg -hide_banner -list_devices true -f dshow -i dummy
ffmpeg -f dshow -video_size 1280x720 -framerate 30 -vcodec mjpeg -i video="YOUR SONY DEVICE" -t 30 -c:v copy sony-test.avi
ffprobe -v error -select_streams v:0 -show_entries packet=size -of csv=p=0 sony-test.avi | Measure-Object -Average -Maximum

1G · Admit inbound camera traffic. On the trusted field Ethernet interface choose the Windows Private network profile. Check Get-NetConnectionProfile and ipconfig for the interface and IPv4 address. Measure the offsets on your rig

2D · Record the same event in every channel. Aim every camera at one clapper or a pair of hands. Put the master mic beside it. Set existing video delays and the master sync offset to zero. Record the composite locally after all streams have settled for a minute. Make five sharp claps roughly 10 seconds apart. Open the recording in a frame-accurate editor such as Kdenlive, show the audio waveform and step through each tile to the first frame of hand contact. Note each tile's frame index and the mic transient time on the same recording timeline. A clap avoids separate screen/speaker latency on a phone. Use the recorded program to judge sync.

2E · Calculate video and audio delays. At 30 fps, a frame is 33.333 ms. For each clap convert each camera's frame index to milliseconds: t = frame × 1000 / fps. Use the same zero reference for the waveform. To combine trials, subtract that clap's Sony event time from every camera and the audio. Take the median for each channel across the five trials. With these six medians, the target T is the latest channel, including audio. A video needs round(T − its median) ms. The independent master mic needs a positive Sync Offset of round(T − its median) ms. This calculation also works from a single clap using its absolute event times. Differences between trials show jitter.

2F · Apply and verify. Right-click each Feed - … → Filters → Audio/Video Filters → Video Delay (Async) and enter its calculated video delay. 3B · How failover behaves. The monitor polls the local receiver, reads a low-resolution decimated sample of each wireless feed using FFmpeg, and asks OBS about each Media Source. It checks publisher loss, missing advancing video keyframes and OBS playback. It also compares small OBS source snapshots against the independently changing upstream picture to catch a frozen OBS render. On failure it places the camera's opaque, labeled slate over the feed in that camera's nested scene. Other cameras and the master mic continue. The feed stays enabled underneath, so OBS can recover while covered. When the publisher, decoder and OBS recover, the monitor restores the camera view in every scene. A sustained unhealthy state is debounced for ~3 seconds, and a healthy state for ~2 seconds after qualifying video. Missing keyframes have a separate default ~12-second threshold. Rejoins also wait for new decodable keyframes. Expect a brief detection interval. Check the monitor console for the transition reason.

The default accepts genuine static scenes if timestamps advance. If a camera encodes the exact same image with fresh timestamps, the monitor cannot distinguish that from a perfectly still scene using timestamps alone. For a moving shot, -PixelFreezeSeconds 30 enables the additional repeated-image check. A quiet, locked-off stand camera can legitimately trigger this mode. A manual fallback is available in the nested camera scene: stop the monitor, keep the slate enabled and move the slate above the feed. To resume, start the monitor again. Camera reconnect and app-side Go Live may still require the operator if the camera ends its publish session. Automation covers the OBS output and local decoder recovery.

"""Launch the local field camera receiver, OBS, and wireless monitor on macOS/Linux."""

ROOT = Path(__file__).resolve().parent
SERVER = ROOT / "server"
RUN = ROOT / "run"
CONFIG = SERVER / "mediamtx.yml"
STATE = RUN / "server.pid"
RTMP = 1935
API = 9997
HTTP = build_opener(ProxyHandler({}))


@contextmanager
def exclusive(name, wait=False):
    with (RUN / name).open("a") as lock:
        try:
            fcntl.flock(lock.fileno(), fcntl.LOCK_EX | (0 if wait else fcntl.LOCK_NB))
        except BlockingIOError:
            raise RuntimeError("Another launcher is already monitoring this kit.") from None
        yield  # Closing the fd also releases the lock after a crash.


def executable(name):
    found = shutil.which(str(name))
    if not found:
        raise RuntimeError(f"Cannot run {name}. Verify installation, path and executable permission.")
    return str(Path(found).resolve())


def obs_command(system, override):
    if override:
        return [executable(override)]
    if system == "darwin":
        for apps in (Path("/Applications"), Path.home() / "Applications"):
            obs = apps / "OBS.app/Contents/MacOS/OBS"
            if obs.is_file():
                return [executable(obs)]
    if shutil.which("obs"):
        return [executable("obs")]
    if system == "linux" and shutil.which("flatpak"):
        probe = subprocess.run(["flatpak", "info", "com.obsproject.Studio"],
                               stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
        if probe.returncode == 0:
            return [executable("flatpak"), "run", "com.obsproject.Studio"]
    raise RuntimeError("Install OBS Studio or supply --obs /full/path/to/the/OBS/executable.")


def obs_is_open():
    # ps comm is the executable name/path, independent of its arguments.
    entries = subprocess.check_output(["ps", "-U", str(os.getuid()), "-o", "stat=", "-o", "comm="],
                                      text=True)
    for line in entries.splitlines():
        state, name = line.strip().split(None, 1)
        if not state.startswith("Z") and Path(name).name in {"obs", "OBS"}:
            return True
    return False


def port_open(port):
    try:
        with socket.create_connection(("127.0.0.1", port), timeout=0.3):
            return True
    except OSError:
        return False


def api_ready():
    try:
        with HTTP.open(f"http://127.0.0.1:{API}/v3/paths/list?itemsPerPage=1", timeout=0.6) as r:
            return isinstance(json.load(r)["items"], list)
    except (OSError, ValueError, KeyError, TypeError):
        return False


def is_kit_server(pid, binary, system):
    """A stale PID or unrelated RTMP server must never be adopted as this kit."""
    if pid <= 1:
        return False
    if system == "linux":
        try:
            cmd = Path(f"/proc/{pid}/cmdline").read_bytes().split(b"\0")
            return cmd[:2] == [os.fsencode(binary), os.fsencode(CONFIG)]
        except OSError:
            return False
    result = subprocess.run(["ps", "-ww", "-p", str(pid), "-o", "command="],
                            capture_output=True, text=True)
    return result.returncode == 0 and result.stdout.strip() == f"{binary} {CONFIG}"


def owns_listeners(pid, system):
    if system == "darwin":
        # A stock macOS installation provides /usr/sbin/lsof to the user that
        # launched this process. Scope each query to both its PID and one port.
        return all(subprocess.run(["/usr/sbin/lsof", "-nP", "-a", "-p", str(pid),
                                   f"-iTCP:{port}", "-sTCP:LISTEN", "-t"],
                                  stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL).returncode == 0
                   for port in (RTMP, API))
    ports = set()
    try:
        inodes = set()
        for fd in Path(f"/proc/{pid}/fd").iterdir():
            with suppress(OSError):  # The server can close a descriptor mid-scan.
                inodes.add(os.readlink(fd))
        for family in ("tcp", "tcp6"):
            table = Path("/proc/net") / family
            if not table.exists():
                continue
            for line in table.read_text().splitlines()[1:]:
                fields = line.split()
                if fields[3] == "0A" and f"socket:[{fields[9]}]" in inodes:
                    ports.add(int(fields[1].split(":")[-1], 16))
    except (OSError, ValueError, IndexError):
        return False
    return {RTMP, API}.issubset(ports)


def ensure_server(binary, system):
    if not CONFIG.is_file():
        raise RuntimeError(f"Missing receiver configuration: {CONFIG}")
    try:
        previous = int(STATE.read_text().strip())
    except (OSError, ValueError):
        previous = 0
    previous_valid = is_kit_server(previous, binary, system)
    if not previous_valid and any(port_open(p) for p in (RTMP, API)):
        raise RuntimeError("TCP 1935 or 9997 is occupied by a service outside this launcher's PID record. "
                           "Inspect it before starting the kit.")
    child = None
    if previous_valid:
        pid = previous
    else:
        with (RUN / "mediamtx.log").open("ab") as log:
            child = subprocess.Popen([binary, str(CONFIG)], cwd=SERVER, stdin=subprocess.DEVNULL,
                                     stdout=log, stderr=subprocess.STDOUT, start_new_session=True)
        pid = child.pid
        STATE.write_text(f"{pid}\n")
    deadline = time.monotonic() + 10
    while time.monotonic() < deadline:
        if child is not None and child.poll() is not None:
            break
        if owns_listeners(pid, system) and port_open(RTMP) and api_ready():
            print(f"MediaMTX PID {pid} ready on TCP {RTMP}; localhost API {API} is responding.", flush=True)
            return
        time.sleep(0.25)
    # Cleanup only a failing child started during this invocation.
    if child is not None and child.poll() is None:
        child.terminate()
        try:
            child.wait(timeout=3)
        except subprocess.TimeoutExpired:
            child.kill()
            child.wait()
    raise RuntimeError(f"MediaMTX did not own both listeners and answer its API. Inspect {RUN / 'mediamtx.log'}.")

                        "--pixel-freeze", str(args.pixel_freeze), "--cameras", *args.cameras]
            runpy.run_path(sys.argv[0], run_name="__main__")

def usb_cameras(net_root=Path("/sys/class/net")):

        raise CameraError("Linux network sysfs is unavailable. Run this on the camera host with /sys/class/net mounted.")
    cameras = []
    for interface in sorted(net_root.iterdir()):
        device = (interface / "device").resolve()
        for ancestor in (device, *device.parents):
            if not (ancestor / "idVendor").is_file():

                        product_file = ancestor / "product"
                        product = product_file.read_text().strip() if product_file.is_file() else "GoPro"
                        cameras.append(Camera(interface.name, product, match[1]))
            break
    return cameras


def ip_json(*args):
    result = subprocess.run(
        ["ip", "-j", "-4", *args], capture_output=True, text=True, timeout=5
    )
    if result.returncode:
        raise CameraError(result.stderr.strip() or "iproute2 did not return the requested network information.")
    return json.loads(result.stdout)


def usb_host_address(camera):
    """Use an on-link IPv4 address and verify the route without overriding it."""
    address = ipaddress.IPv4Address(camera.address)
    candidates = []
    for link in ip_json("address", "show", "dev", camera.interface):
        for addr in link.get("addr_info", []):
            if addr.get("family") != "inet":
                continue
            local = ipaddress.IPv4Interface(f"{addr['local']}/{addr['prefixlen']}")
            if local.ip != address and address in local.network:
                candidates.append(str(local.ip))
    if not candidates:
        raise CameraError(f"No on-link USB IPv4 address for {camera.address} on {camera.interface}. "
                          "Power on the GoPro, enable IPv4 DHCP for that USB interface, and retry.")
    for local in candidates:
        routes = ip_json("route", "get", camera.address, "from", local)
        if any(r.get("dev") == camera.interface and not r.get("gateway")
               and r.get("type", "unicast") == "unicast" for r in routes):
            return local
    raise CameraError(f"The kernel routes {camera.address} outside {camera.interface} or through a gateway. "
                      "Check for overlapping camera, LAN, VPN, or container subnets.")


def choose(cameras, interface=None, serial=None):
    selected = [c for c in cameras if (not interface or c.interface == interface)
                and (not serial or c.suffix == serial)]
    if len(selected) != 1:
        if not selected:
            raise CameraError("No matching GoPro USB network device. Check cable, power, network mode and filters. "
                              "Use 'list' and 'ip -br address' to inspect.")
        raise CameraError("Multiple GoPro USB interfaces found. Select one with --interface or --serial.")
    return selected[0]


STATES = {0: "off", 1: "idle", 2: "streaming", 3: "low-power preview"}


class Controller:
    def __init__(self, camera, host, *, http_port=8080):
        self.camera = camera
        self.host = host
        self.http_port = http_port

    def call(self, path):
        # Direct TCP, no DNS, redirects or proxy. Bind the source used for the camera's reply stream.
        conn = http.client.HTTPConnection(
            self.camera.address, self.http_port, timeout=4, source_address=(self.host, 0)
        )
        try:
            conn.request("GET", "/gopro/" + path)
            response = conn.getresponse()
            raw = response.read(65537)
            if response.status != 200:
                raise CameraError(f"GoPro {path} returned HTTP {response.status}. "
                                  "Check the camera's idle state and its firmware.")
            if len(raw) > 65536:
                raise CameraError("Unexpected GoPro response size.")
            result = json.loads(raw)
        finally:
            conn.close()
        if not isinstance(result, dict):
            raise CameraError(f"Unexpected GoPro reply to {path}.")
        if (path.startswith("webcam/") or "error" in result) and result.get("error") != 0:
            raise CameraError(f"GoPro rejected {path}: {result}.")
        return result

    def status(self):
        status = self.call("webcam/status").get("status")
        if type(status) is not int or status not in STATES:
            raise CameraError(f"Unknown GoPro webcam state: {status!r}.")
        return status

    def wait(self, expected):
        deadline = time.monotonic() + 7
        while True:
            current = self.status()
            if current in expected:
                return current
            if time.monotonic() >= deadline:
                raise CameraError(f"GoPro remained {STATES[current]}. Use 'status' before retrying.")
            time.sleep(0.25)

    def start(self):
        state = self.status()
        if state == 2:
            return "Already streaming. Existing settings were preserved. Check the live picture in OBS."
        if state == 3:
            raise CameraError("Another client has a preview session. Close it or run 'stop' before 'start'.")
        # GoPro's multi-webcam reference releases USB command-and-control before starting webcam.
        self.call("camera/control/wired_usb?p=0")
        self.call("webcam/start?res=12&port=8554&protocol=TS")
        self.wait({2})
        return "GoPro reports 1080p webcam mode started. Confirm moving video in OBS."

    def stop(self):
        state = self.status()
        if state in (2, 3):
            self.call("webcam/stop")
            state = self.wait({0, 1})
        if state == 1:
            self.call("webcam/exit")
        # Some firmware reports idle rather than off on a USB connection even after exit.
        self.wait({0, 1})
        return "GoPro webcam stream is stopped."

def usb_address(value, *, verify_local):
    address = IPv4Address(value)
    if address.is_unspecified or address.is_loopback or address.is_multicast or address.is_reserved:
        raise ValueError("Use the unicast IPv4 address assigned to the PC's GoPro USB interface.")
    if verify_local:
        try:
            with socket.socket(socket.AF_INET, socket.SOCK_DGRAM) as sock:
                sock.bind((str(address), 0))
        except OSError as exc:
            raise ValueError(f"{address} is not available on this host. Connect the GoPro "
                             "and use the PC-side USB address displayed by the helper.") from exc
    return str(address)

def provision(client, gopro_usb_bind=None, gopro_wireless=False):
    def call(request, **fields):
        return client.send(request, fields, raw=True) or {}

    profile = call("GetProfileList")["currentProfileName"]
    collection = call("GetSceneCollectionList")["currentSceneCollectionName"]
    if profile != FIELD or collection != FIELD:
        raise ValueError(f"Select '{FIELD}' in both Profile and Scene Collection in OBS first. "
                         f"Current selections: {profile!r} / {collection!r}.")
    for request in ("GetStreamStatus", "GetRecordStatus"):
        if call(request)["outputActive"]:
            raise ValueError("Run setup while OBS is offline, after stopping recording and streaming.")

    kinds = set(call("GetInputKindList")["inputKinds"])
    os_name = platform.system()
    native_kinds = {"Windows": ("dshow_input",), "Darwin": ("macos-avcapture", "av_capture_input"),
                    "Linux": ("v4l2_input",)}
    native = next((kind for kind in native_kinds.get(os_name, ()) if kind in kinds), None)
    if native is None or not {"image_source", "ffmpeg_source"}.issubset(kinds):
        raise ValueError(f"{os_name} OBS must provide its native camera input, Image, and Media Source. "
                         f"Expected camera input: {native_kinds.get(os_name)}.")
    if gopro_usb_bind is not None and gopro_wireless:
        raise ValueError("Choose one Linux GoPro input transport.")
    if os_name != "Linux" and (gopro_usb_bind is not None or gopro_wireless):
        raise ValueError("The GoPro transport options apply only to a native Linux OBS host.")

    inputs = {item["inputName"]: item for item in call("GetInputList")["inputs"]}
    scenes = {item["sceneName"] for item in call("GetSceneList")["scenes"]}
    camera_scenes = [f"Cam - {camera}" for camera in CAMERAS]
    scene_names = camera_scenes + [GRID, PIP]
    feeds = {}
    assets = {}
    corrections = {}
    for camera, key in CAMERAS.items():
        asset = slate_path(camera)
        if not asset.is_file():
            raise ValueError(f"Missing {asset.name}. Extract the complete kit with its assets folder.")
        assets[camera] = asset
        slate = f"Slate - {camera}"
        feed = f"Feed - {camera}"
        for name in (slate, feed):
            if name in scenes:
                raise ValueError(f"An existing scene uses the input name {name!r}.")
        if slate in inputs:
            current_kind = re.sub(r"_v\d+$", "", inputs[slate]["inputKind"])
            if current_kind == "image_source":
                current = call("GetInputSettings", inputName=slate)["inputSettings"]
                old_file = current.get("file")
                if not old_file or not Path(old_file).is_file():
                    corrections[slate] = {"file": str(asset)}
            elif os_name != "Windows" or current_kind != "text_gdiplus":
                raise ValueError(f"{slate!r} must be an Image source or an existing Windows Text (GDI+) slate.")
        if key:
            kind = "ffmpeg_source"
            settings = media_settings(f"rtmp://127.0.0.1:1935/live/{key}")
        elif camera == "GoPro USB" and os_name == "Linux":
            kind = "ffmpeg_source"
            settings = {}
        else:
            kind = native
            settings = {}
            if native == "dshow_input":
                settings = {"video_device_id": "", "deactivate_when_not_showing": False}
        if feed in inputs:
            existing = inputs[feed]["inputKind"]
            if os_name == "Darwin" and not key and existing in native_kinds["Darwin"] and existing in kinds:
                kind = existing
            elif existing != kind:
                raise ValueError(f"{feed!r} uses {existing!r}. Expected {kind!r}.")
        if camera == "GoPro USB" and os_name == "Linux":
            current = call("GetInputSettings", inputName=feed)["inputSettings"] if feed in inputs else {}
            wireless = gopro_wireless or (gopro_usb_bind is None and current.get("input") == PRIMARY_RTMP)
            if wireless:
                settings = media_settings(PRIMARY_RTMP)
            elif gopro_usb_bind is not None:
                settings = media_settings(usb_url(usb_address(gopro_usb_bind, verify_local=True)), "mpegts")
            else:
                settings = media_settings(usb_url(saved_usb_address(current)), "mpegts")
            if feed in inputs and (gopro_wireless or gopro_usb_bind is not None):
                # The source remains an ffmpeg_source in either mode, keeping its filters and scene references.

                                                    "clear_on_media_end") if current.get(k) != settings[k]}
                if changes:

    for name in scene_names:

    for name in scene_names:

            call("CreateScene", sceneName=name)

        items = call("GetSceneItemList", sceneName=scene)["sceneItems"]
        matches = [item for item in items if item["sourceName"] == source]
        if len(matches) > 1:
            raise ValueError(f"Multiple copies of {source!r} in {scene!r}. Keep one, then rerun.")
        if matches:
            item_id = matches[0]["sceneItemId"]
        elif kind is not None and source not in inputs:

                          inputSettings=settings, sceneItemEnabled=True)
            item_id = result["sceneItemId"]
            inputs[source] = {"inputKind": kind}
        else:
            item_id = call("CreateSceneItem", sceneName=scene, sourceName=source,
                           sceneItemEnabled=True)["sceneItemId"]
        item = {"sceneName": scene, "sceneItemId": item_id}
        call("SetSceneItemTransform", **item, sceneItemTransform=transform(box))

    for camera, (kind, settings) in feeds.items():
        scene = f"Cam - {camera}"
        slate = place(scene, f"Slate - {camera}", FRAME, "image_source",
                      {"file": str(assets[camera]), "unload": False})
        call("SetSceneItemEnabled", **slate, sceneItemEnabled=True)
        call("SetSceneItemIndex", **slate, sceneItemIndex=0)
        feed = f"Feed - {camera}"
        place(scene, feed, FRAME, kind, settings)
        # V4L2 provides video only. Its separate USB audio device belongs in the master mixer.
        if kind != "v4l2_input":
            call("SetInputMute", inputName=feed, inputMuted=True)

        for camera, box in layout.items():
            item = place(scene, f"Cam - {camera}", box)
            call("SetSceneItemEnabled", **item, sceneItemEnabled=True)

def probe_command(ffmpeg, url, stale):
    # Intra frames only. The select filter emits only when source timestamps
    # advance, and passthrough prevents output frame-rate synthesis on a stall.
    return [ffmpeg, "-hide_banner", "-loglevel", "error", "-nostdin",
            "-rw_timeout", str(int(1_000_000 * stale)), "-analyzeduration", "1000000",
            "-probesize", "1000000", "-threads", "1", "-skip_frame", "nokey",
            "-i", url, "-map", "0:v:0", "-an", "-sn", "-dn",
            "-vf", "select='isnan(prev_selected_t)+gte(t-prev_selected_t,0.5)',"
                   "scale=96:54:flags=area,format=gray",
            "-fps_mode", "passthrough", "-threads:v", "1", "-c:v", "rawvideo",
            "-flush_packets", "1", "-f", "rawvideo", "pipe:1"]


class VideoProbe:
    def __init__(self, ffmpeg, key, stale, pixel_freeze):
        self.url = f"rtmp://127.0.0.1:1935/live/{key}"
        self.command = probe_command(ffmpeg, self.url, stale)
        self.stale, self.pixel_freeze = stale, pixel_freeze
        self.process = None
        self.lock = threading.Lock()
        self.next_start = 0.0
        self.started = 0.0
        self.frames = 0
        self.changes = 0
        self.last_frame = self.changed = 0.0
        self.previous = None

    def start(self, now):
        proc = subprocess.Popen(
            self.command, stdout=subprocess.PIPE, stdin=subprocess.DEVNULL,
            stderr=subprocess.DEVNULL, creationflags=getattr(subprocess, "CREATE_NO_WINDOW", 0)
        )
        with self.lock:
            self.process = proc
            self.started = now
            self.frames = 0
            self.last_frame = self.changed = 0.0
            self.previous = None
        threading.Thread(target=self.read_frames, args=(proc,), daemon=True).start()

    def read_frames(self, proc):
        with proc.stdout as pipe:
            while len(frame := pipe.read(FRAME_BYTES)) == FRAME_BYTES:
                now = time.monotonic()
                with self.lock:
                    if self.process is not proc:
                        break
                    self.frames += 1
                    self.last_frame = now
                    if frame != self.previous:
                        self.changes += 1
                        self.changed = now
                    self.previous = frame

    def stop(self):
        with self.lock:
            proc, self.process = self.process, None
        if proc is not None:
            if proc.poll() is None:
                with suppress(ProcessLookupError):
                    proc.kill()
            proc.wait()

    def check(self, now, publisher):
        if publisher is False:
            self.stop()
            self.next_start = 0.0
            return False, "publisher offline"
        if self.process is not None and self.process.poll() is not None:
            self.stop()
            self.next_start = now + 2
        if self.process is None and now >= self.next_start:
            self.start(now)
        with self.lock:
            frames, last, changed = self.frames, self.last_frame, self.changed
        if self.process is None:
            return False, "retrying decoder"
        if now - (last or self.started) > self.stale:
            self.stop()
            self.next_start = now + 1
            return False, "video timestamps stalled"
        if frames < 2:
            return False, "waiting for two video keyframes"
        if self.pixel_freeze and now - changed > self.pixel_freeze:
            # Keep this decoder open: a later changed frame must clear the fault.
            return False, "repeated image"
        return True, "decoded video"


class RenderCheck:
    """Detect a frozen OBS picture if the camera independently shows movement."""
    def __init__(self):
        self.shot = None
        self.sample_at = 0.0
        self.last_change = 0.0
        self.change_count = 0
        self.stuck = False
        self.recovery_changes = 0
        self.unavailable = False

    def ready(self, obs, name, now, changes):
        if now < self.sample_at:
            return not (self.stuck or self.unavailable)
        self.sample_at = now + 3
        active = obs.get_source_active(name)
        if not (active.video_active or active.video_showing):
            self.shot, self.stuck, self.unavailable = None, False, False
            self.recovery_changes = 0
            return True
        from obsws_python.error import OBSSDKRequestError
        try:
            shot = obs.get_source_screenshot(name, "png", 96, 54, -1).image_data
        except OBSSDKRequestError:
            # An active source can report Playing while lacking a drawable image.
            self.shot, self.unavailable = None, True
            return False
        self.unavailable = False
        if shot != self.shot:
            self.shot = shot
            self.last_change, self.change_count = now, changes
            if self.stuck:
                self.recovery_changes += 1
                if self.recovery_changes >= 2:
                    self.stuck = False
                    self.recovery_changes = 0
        elif now - self.last_change >= 15 and changes - self.change_count >= 3:
            self.stuck = True
            self.recovery_changes = 0
        return not self.stuck


class Switch:
    def __init__(self, title):
        self.title = title
        self.scene = "Cam - " + title
        self.feed = "Feed - " + title
        self.slate = "Slate - " + title
        self.candidate = None
        self.since = 0.0
        self.notice = None
        self.next_restart = 0.0
        self.render = RenderCheck()

    def report(self, text):
        if text != self.notice:
            log(f"{self.title}: {text}")
            self.notice = text

    def update(self, obs, signal_good, reason, now, changes):
        items = obs.get_scene_item_list(self.scene).scene_items
        feeds = [x for x in items if x["sourceName"] == self.feed]
        slates = [x for x in items if x["sourceName"] == self.slate]
        if len(feeds) != 1 or len(slates) != 1:
            self.report("check unique Feed and Slate items in the camera scene")
            self.candidate = None
            return
        feed, slate = feeds[0], slates[0]
        if self.title == CAMERAS["gopro1"]:
            # The primary slot may alternatively contain a direct USB decoder.
            settings = obs.get_input_settings(self.feed)
            if (settings.input_kind != "ffmpeg_source" or
                    settings.input_settings.get("input") != "rtmp://127.0.0.1:1935/live/gopro1"):
                self.report("primary slot uses USB; omit gopro1 from wireless monitoring")
                self.candidate = None
                return
        if (feed.get("inputKind") != "ffmpeg_source" or not slate["sceneItemEnabled"]
                or not feed["sceneItemEnabled"]):
            self.report("enable both the Media Source and its opaque slate; monitoring paused")
            self.candidate = None
            return
        good = signal_good
        if signal_good:
            state = obs.get_media_input_status(self.feed).media_state
            if state != "OBS_MEDIA_STATE_PLAYING":
                good, reason = False, state
            elif not self.render.ready(obs, self.feed, now, changes):
                good, reason = False, "OBS picture unavailable or stalled"
        else:
            self.render = RenderCheck()
        if good != self.candidate:
            self.candidate, self.since = good, now
        if now - self.since < (2.0 if good else 3.0):
            return
        # Change only z-order in this two-layer camera view. The decoder remains
        # active behind the opaque slate and every parent layout sees the change.
        visible = feed["sceneItemIndex"] > slate["sceneItemIndex"]
        if visible != good:
            if not right_workspace(obs):
                return
            obs.set_scene_item_index(self.scene, slate["sceneItemId"], feed["sceneItemIndex"])
        self.report("live" if good else f"slate ({reason})")
        if signal_good and not good and now >= self.next_restart and now - self.since >= 6:
            active = obs.get_source_active(self.feed)
            if (active.video_showing or active.video_active) and right_workspace(obs):
                obs.trigger_media_input_action(self.feed, "OBS_WEBSOCKET_MEDIA_INPUT_ACTION_RESTART")
                self.next_restart = now + 25
                log(f"{self.title}: restarted OBS Media Source behind its slate.")


def right_workspace(client):
    return (client.get_scene_collection_list().current_scene_collection_name == WORKSPACE
            and client.get_profile_list().current_profile_name == WORKSPACE)


def main():
    p = argparse.ArgumentParser(description=__doc__)
    p.add_argument("--cameras", nargs="+", choices=CAMERAS, default=list(DEFAULT_CAMERAS))
    p.add_argument("--ffmpeg", default="ffmpeg")
    p.add_argument("--stale", type=int, default=12, metavar="SECONDS",
                   help="restart probe after this gap in video keyframes (default 12)")
    p.add_argument("--pixel-freeze", type=int, default=0, metavar="SECONDS",
                   help="also slate repeated 96x54 images; 0 disables this optional heuristic")
    p.add_argument("--port", default=int(os.getenv("OBS_WS_PORT", "4455")), type=int)
    args = p.parse_args()
    if args.stale < 4 or args.pixel_freeze < 0 or not 1 <= args.port <= 65535:
        p.error("--stale must be >=4; --pixel-freeze >=0; --port 1..65535")
    ffmpeg = shutil.which(args.ffmpeg)
    if not ffmpeg:
        p.error("FFmpeg is missing. Install FFmpeg or supply --ffmpeg.")
    try:
        import obsws_python
        from obsws_python.error import OBSSDKRequestError
    except ImportError:
        p.error("Install obsws-python in this Python environment.")
    logging.getLogger("obsws_python").setLevel(logging.CRITICAL)
    password = os.environ.get("OBS_WS_PASSWORD") or getpass.getpass("OBS WebSocket password: ")
    if not password:
        p.error("Enter the password shown by OBS under Tools > WebSocket Server Settings.")
    probes = {key: VideoProbe(ffmpeg, key, args.stale, args.pixel_freeze)
              for key in dict.fromkeys(args.cameras)}
    switches = {key: Switch(CAMERAS[key]) for key in probes}
    client, notice, api_available = None, None, None
    try:
        while True:
            try:
                if client is None:
                    client = obsws_python.ReqClient(host="127.0.0.1", port=args.port,
                                                    password=password, timeout=3)
                if not right_workspace(client):
                    if notice != "workspace":
                        log("Paused. Select Field Stream under both Profile and Scene Collection.")
                        notice = "workspace"
                    for probe in probes.values():
                        probe.stop()
                    for switch in switches.values():
                        switch.candidate = None
                    time.sleep(3)
                    continue
                if notice != "online":
                    log("Watching " + ", ".join(CAMERAS[key] for key in probes) + ". Ctrl+C stops the monitor.")
                    notice = "online"
                paths = online_paths()
                if (paths is not None) != api_available:
                    api_available = paths is not None
                    log("MediaMTX API online." if api_available else
                        "MediaMTX API unavailable; using decoded frames for publisher health.")
                for key, probe in probes.items():
                    now = time.monotonic()
                    good, reason = probe.check(now, None if paths is None else f"live/{key}" in paths)
                    try:
                        switches[key].update(client, good, reason, now, probe.changes)
                    except OBSSDKRequestError as exc:
                        switches[key].candidate = None
                        switches[key].report(f"OBS request failed ({exc}); verify the scene and source names")
                time.sleep(POLL)
            except (KeyboardInterrupt, SystemExit):
                raise
            except Exception as exc:
                # Reconnect to OBS after a restart instead of replacing program scenes.
                if notice != "error":
                    log(f"Connection/monitor error ({type(exc).__name__}: {exc}). Retrying in 3 s.")
                    notice = "error"
                if client is not None:
                    with suppress(Exception):
                        client.disconnect()
                client = None
                time.sleep(3)
    except KeyboardInterrupt:
        log("Monitor stopped.")
    finally:
        for probe in probes.values():
            probe.stop()
        if client is not None:
            with suppress(Exception):
                client.disconnect()


if __name__ == "__main__":
    main()
